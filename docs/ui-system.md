# 工作台 UI 规范与本轮统一

本轮沿用 Taste v2 的视觉审查方法，结合编辑器的操作密度统一工作台。Taste v2 主要面向展示网站，因此没有套用其营销页面版式、大字号或入场动画数量要求。简历纸张本身保留各模板的字体、颜色和排版。

## 组件规范

统一样式按职责存放在 `app/styles/`：`theme.css` 定义主题与控件变量，`workbench.css` 定义 `.app-ui` 工作台控件，`resume.css` 定义简历模板，`print.css` 定义打印规则；`app/globals.css` 仅负责导入和基础规则。简历纸张本身保留各模板的字体、颜色和排版。

| 项目 | 约定 |
| --- | --- |
| 按钮、输入框、聊天输入框 | 12px 圆角 |
| 菜单外层 / 菜单行 | 12px / 8px 圆角，外层内边距 6px |
| 面板、通知、消息气泡 | 16px 圆角 |
| 模态对话框 | 20px 圆角 |
| 简历照片、色点、助手启动按钮 | 照片采用一寸证件照 25:35 竖版比例；色点与助手启动按钮保留圆形 |
| 贴边、铺满区域的底部导航 | 直角平面高亮，无选中顶线、阴影或透明模糊；不继承普通按钮圆角 |
| 主操作 | 实色强调色，用于导出等主要动作 |
| 选中状态 | 浅绿色底色、深色文字，与主操作区分 |
| 悬停状态 | 中性底色；仅有精确指针时启用悬停反馈 |
| 焦点 | 普通控件使用 2px 描边；菜单使用行高亮，强制颜色模式补充描边 |
| 阴影 | 静态工具栏和普通按钮无阴影；浮层、对话框使用共享阴影 |
| 控件高度 | 桌面按钮至少 36px、表单至少 40px；小于 1024px 时至少 44px |
| 字号 | 工作台按钮 13px、表单 14px，手机表单 16px；辅助文字至少 12px |
| 动效 | 高频浮层共用 120ms 缓动，普通反馈保留 180ms；下拉选项即时开关，移除按钮悬停位移和表单逐项入场 |

代码编辑区保留等宽字体。纸张投影用于识别分页，未纳入普通卡片阴影规则。

## 交互与流畅性

- 设置、样式面板使用共享 AnchoredPanel，按可视视口限制高度，内容内部滚动。手机采用模态背景，避免助手遮挡。
- useOverlayDialog 统一打开焦点、Escape、模态 Tab 循环和关闭后焦点归还。嵌套 Select 先处理自身 Escape。
- 普通操作菜单使用 `ui/dropdown-menu.tsx` 的 Base UI 包装，统一定位、外部关闭、方向键、Home、End 和焦点恢复。项目菜单保留重命名、删除确认的专用结构；导出加载和成功时保持按钮尺寸。
- 颜色按钮、滑杆和 AI 配置表单具备可访问名称。通知提供可键盘操作的关闭按钮，独立挂载到 body，避免被模态背景 inert 禁用。
- 缩放百分比显示实际纸张缩放，适应操作恢复适应比例。
- 输入立即更新，停止输入 80ms 后解析最新版本；预览更新期间标记分页未完成，导出等待最新分页。
- 分页过程局部缓存几何测量；项目更新对基本类型避免重复 JSON 序列化。缓存不跨编辑或主题变化复用。

## 验证边界

本轮新增 `e2e/ui-consistency.spec.ts`，覆盖短屏设置、嵌套 Select、助手焦点、触控色板、导出尺寸、明暗样式、320px CSS 弹窗及编辑后立即导出。共享 fixtures 检查浏览器运行时错误和 hydration 警告。

采用 Vitest、Playwright 的桌面 Chromium 和手机视口模拟，以及截图人工复核。运行结果以交付说明为准。手机视口模拟不等于实体手机测试；没有采集 FPS 或量化输入延迟，不能据此声称帧率或速度提升百分比。

本轮最终验证：lint、typecheck、生产构建通过；完整 Vitest 137/137 通过，收尾后相关组件 19/19 通过；最终生产构建 Playwright 66/66 通过（55.7 秒），页头覆盖 320–1920px。开发模式完整回归 62/62 通过，随后新增的弹窗和立即导出用例 4/4、页头修复用例 2/2 通过。最终生产回归未捕获 hydration 或运行时异常。生产截图保存在本次会话的 `ui-unification-result` 目录。

构建保留一条已有提示：ESLint 配置未检测到 Next.js 专用插件；本轮 lint 和构建均未因此失败。本轮没有删除用户数据或已有回归测试。

## 下拉遮挡补充修复

用户反馈后复现：Select 内部列表虽然有 240 的 z-index，但外层 Positioner 创建了层级为 100 的独立堆叠上下文，仍位于设置面板 120 之下。统一将 Select 与 DropdownMenu 的外层定位容器提升到 240；仅检查内部列表层级不足以证明不会遮挡。

新增回归在修复前桌面、移动端均因选项中心被遮挡失败，修复后提供商、模型、字体都能真实点击；另验证 568px 短屏和字体长列表最后一项。开发模式相关 UI 回归 18/18 通过，补充边界回归 2/2 通过，ESLint 和类型检查通过。本次未重跑生产构建或完整业务回归。

## 下拉与二级浮层样式精修

- 菜单外层使用 12px 圆角和 6px 留白，选项使用 8px 圆角；桌面行高至少 36px，触控行高至少 44px。项目、导出、更多菜单共用 `.ui-menu` 与 `.ui-menu-item`。
- Select 在触发器下方留出 8px 间距，保留当前值，空间不足时由 Base UI 翻转定位；屏幕边缘留 12px，长列表限制可用高度并内部滚动。
- 选中使用浅绿底色与尾部勾选；键盘高亮和悬停使用中性色。强制颜色模式保留键盘描边。图标 16px、图文间距 8px，长名称省略并保留模型、字体标题。
- Provider 与语言值显式映射展示名称；自定义模型显示本地化标签，避免显示内部标识符。Select 收起与展开名称一致。
- 项目菜单整行标记当前简历，预留勾选位置，重命名和删除按钮使用统一尺寸；新建入口与项目列表分组。
- 共享 DropdownMenu 的子菜单、勾选项、单选项和分组项也使用相同规则；子菜单保留 6px 间距及边缘碰撞处理。现有页面没有使用级联子菜单入口，因此本轮浏览器验证覆盖的是实际展示的项目、导出、更多和设置下拉。
- 高频 Select 即时开关，取消缩放入场与退出等待。回归曾捕获退出淡出吞掉快速第二次 Escape，移除后保持连续关闭可用。

新增 `e2e/menu-style.spec.ts`：验证实际计算圆角和留白、下拉不覆盖触发器、选中与普通项区分、模型标签、明暗主题，并保存项目、导出、更多菜单截图。

精修后最终验证：lint、类型检查、生产构建通过；完整 Vitest 137/137 通过，生产 Playwright 70/70 通过（约 1 分钟）。明暗桌面截图和移动菜单截图已实际复核。没有新增依赖、删除用户数据或修改线上环境。

## 简化颜色与滑杆布局

移除样式面板中的辅色编辑入口及其专用预设色。辅色仍被次级文字和 DOCX 使用，因此保留已保存的 secondaryColor 与导出兼容逻辑，避免旧简历改变颜色。

四组滑杆统一为标签在上、滑杆与数值在下；数值与单位组合成一个控件。统一 4px 轨道和 16px 滑块，提供 36/44px 操作高度，修复默认浏览器滑杆外观和窄屏拥挤。短屏滚动预留焦点边框空间。

相关 ESLint、类型检查和样式面板组件测试通过；开发浏览器针对性回归 6/6 通过，滚动留白调整后补测 2/2 通过，并实际复核桌面与 320px 窄屏截图。本次未重跑完整生产测试。

## 分割线与强调色命名修正

将“主色 / Primary Color”改为“强调色 / Accent Color”，保留主题字段 primaryColor 兼容已有数据。移除颜色区重复标题和字体、滑杆之间的多余横线，统一分组间距。

此前恢复默认区域的上边线直接接在最后一组控件底边，只有按钮内部上留白；现在 AnchoredPanel 支持独立 footer，内容滚动与底栏分离，分割线两侧均留 16px 空间，短屏恢复默认按钮保持可见。新增回归在旧实现因间距只有 17px 而失败；修复后验证数值框底边距分割线至少 12px、恢复默认按钮距末项至少 24px。

相关开发浏览器回归 20/20、组件测试 6/6、ESLint、类型检查通过；实际复核桌面与 320px 短屏截图。此次未重跑完整生产构建。

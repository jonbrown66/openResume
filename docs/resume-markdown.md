# 简历 Markdown 写法与样式对照表

这份指南对应 openResume 当前的四种简历模板。Markdown 决定“这是什么内容”，模板和“样式”面板决定“它长什么样”。相同内容在不同模板中的位置、装饰线和对齐方式可能不同。

不熟悉 Markdown 时，可以直接切换到“区块”，按字段填写姓名、联系方式、工作和教育经历。Markdown 编辑区顶部的“写法”按钮也能打开本指南的常用规则和完整示例。

## 三步上手

1. 修改示例顶部的姓名、求职岗位和联系方式。保留英文字段名、半角冒号以及前后的两行 `---`。
2. 按章节填写经历，把每项职责或成果写成一条列表。
3. 查看预览，用模板和“样式”面板调整字体、强调色、字号、行高、章节间距与页边距。手机上通过“编辑 / 预览”切换。

复制示例只会写入剪贴板，不会覆盖已有简历。需要替换内容时，请自行粘贴；不要把另一份完整示例直接接在原简历末尾，否则会产生第二套基本信息和重复章节。

## 写法 → 显示效果

| 要写什么 | Markdown 写法 | 简历中的效果 | 注意事项 |
| --- | --- | --- | --- |
| 姓名 | `name: 张三` | 简历顶部姓名 | 放在开头的两行 `---` 之间，不要用 `# 张三` 代替。 |
| 求职岗位 | `title: 前端工程师` | 姓名附近的岗位说明 | 字段名保留英文；值可用中文或英文。 |
| 联系方式 | `contact: 邮箱 \| 电话 \| 城市` | 联系信息，模板会用间隔符分开 | 使用半角 `\|` 分项；这里是纯文本，不解析 Markdown 链接或加粗。 |
| 个人简介 | `## 个人简介`，下一段写简介正文 | 独立简介区域 | 放在第一个章节；也可用 Summary、Profile、About 等可识别标题。 |
| 章节 | `## 工作经历` | 章节标题和模板对应的分组样式 | `##` 后留一个空格。教育经历、项目经历、技能等同理。 |
| 单条经历 | `### 前端工程师` | 经历标题 | `###` 后留空格。公司、职责等写在这条经历下。 |
| 经历时间 | `### 前端工程师 \| 2023.06 - 至今` | 标题及时间/补充信息 | 最后一个半角 `\|` 后的内容作为时间或补充信息；布局由模板决定。 |
| 公司或学校 | 经历标题下一行写 `**示例科技**` | 经历对应的组织名称 | 必须紧跟 `###` 下一行，整行加粗，中间不要插空行；不是正文里的普通加粗。 |
| 分点成果 | `- 加载时间减少 **30%**` | 列表项，数字加粗 | 短横线后留空格，每项单独一行。不要把手工圆点当成 Markdown 列表。 |
| 有序列表 | `1. 完成需求分析` | 编号列表 | 后续项可用 `2.`、`3.`，每项单独一行。 |
| 重点 | `**性能优化**` | 加粗正文 | 标题本身已有层级样式，无需额外加粗。 |
| 补充说明 | `*团队协作项目*` | 斜体正文 | 字体的实际斜体效果取决于所选字体。 |
| 文字链接 | `[作品集](https://example.com)` | 可点击的“作品集” | 用于正文或列表；不要放进顶部的 `contact:` 字段。 |
| 两个段落 | 两段文字之间空一行 | 独立段落 | 单次换行不保证成为独立段落；空行不能当分页控制符。 |
| 表格 | 表头、分隔行、数据行，见下方示例 | 表格 | 第二行的 `---` 分隔单元格不可省略；窄栏、手机和多页排版中优先使用简单列表。 |
| 头像 | 推荐在区块模式上传 | 模板的头像区域 | `image:` 是可选字段；上传后显示的 `[avatar]` 是已有图片的占位符，不是可自行填写的图片地址。 |

## 公司名称和时间怎么写

```markdown
## 工作经历

### 前端工程师 | 2023.06 - 至今
**示例科技**
- 负责官网与管理后台开发。
- 加载时间减少 **30%**。
```

对应关系：

- `## 工作经历`：章节。
- `### 前端工程师`：一条经历的标题。
- `| 2023.06 - 至今`：这条经历的时间信息。
- `**示例科技**`：这条经历的公司名称。注意它与上一行之间没有空行。
- 两个 `-` 开头的行：这条经历的具体描述。

教育、项目经历也可以采用同一结构；公司一栏分别填写学校或项目所属组织。不需要时间时，可省略 `|` 及后面的内容。

## 完整入门示例

```markdown
---
name: 张三
title: 前端工程师
contact: zhangsan@example.com | 138-0000-0000 | 杭州
---

## 个人简介

有 3 年前端开发经验，擅长把复杂流程做得简单易用。

## 工作经历

### 前端工程师 | 2023.06 - 至今
**示例科技**
- 负责官网与管理后台开发，页面加载时间减少 **30%**。
- 与设计、产品协作，完成核心流程优化。

## 教育经历

### 计算机科学与技术 | 2019.09 - 2023.06
**示例大学**
- 本科，主修软件工程、数据结构。

## 技能

- React、TypeScript、CSS
- [作品集](https://example.com)
```

以上名称、联系方式和成果都是示例，请替换为自己的真实信息。

## 可选：表格

```markdown
## 技能

| 技能 | 熟练度 |
| --- | --- |
| React | 熟练 |
| TypeScript | 熟练 |
```

对于简短的技能清单，通常下面这种写法更容易编辑，也更适合窄栏：

```markdown
## 技能

- React：熟练
- TypeScript：熟练
```

## 哪些样式不该靠 Markdown 控制

| 想调整的效果 | 使用哪里 | 避免的做法 |
| --- | --- | --- |
| 字体、字号、行高 | “样式”面板 | 手写 HTML 的字体或字号属性。 |
| 强调色 | “样式”面板 | 给每个标题分别插入颜色代码。 |
| 章节间距、页边距 | “样式”面板 | 连续回车、输入多个空格模拟布局。 |
| 时间位置、分栏、标题装饰 | 切换模板 | 使用空格把时间推到右边。 |
| 内容顺序 | 调整 Markdown 章节或区块顺序 | 改标题层级来模拟视觉字号。 |

不要靠大量空行制造分页。预览会根据页面、字体和内容自动分页，导出前应检查实际页数及最后一页。

## 常见问题

- **章节没有被正确识别**：确认 `##` 或 `###` 后有空格，且使用的是半角 `#`。保留文件最顶部的基本信息区。
- **公司名称变成了普通加粗正文**：检查公司是不是紧跟条目标题的下一行；移除两行之间的空行。
- **时间没有单独显示**：确认使用半角 `|`，并把时间放在条目标题的最后一项。
- **切回 Markdown 出现单独的 `###`**：它保留一条尚未命名的经历，避免只填公司、只填时间或多条未命名经历被合并；补上标题即可。技能清单不需要这一行。
- **字段中出现 `\|`**：这是字段里普通竖线的转义。例如时间中同时包含日期和地点时，区块编辑器会自动转义，避免重新解析时被拆成两个字段。预览仍显示普通竖线。
- **联系方式里的链接符号原样显示**：`contact:` 按纯文本处理。顶部直接填写网址，或把 Markdown 链接移到正文。
- **头像出现 `[avatar]`**：这是编辑区隐藏图片数据后的显示占位，不要用它表示一张尚未上传的图片；到区块模式上传或替换头像。
- **排版不符合预期**：先确认内容层级，再调整模板与样式面板。Markdown 写法一致不代表四种模板的布局完全一致。
- **想整理一份粘贴进来的简历**：“格式整理”会重新识别并生成内容，不只是调整空格，也可能调整标题、简介列表和正文分隔线。检查结果，不满意时撤销。
- **切换区块会不会自动整理全文**：单纯切换模式不会改写原文；在区块模式修改内容后，会根据结构重新生成 Markdown，原始空白和部分写法可能变化。

## 项目规则依据

- `src/utils/resumeDocument.ts`：基本信息、章节、经历、公司和时间的解析，以及格式整理与序列化。
- `src/components/ResumeRenderer.tsx`：内容渲染、联系方式、模板和 Markdown 表格/列表。
- `src/config/markdownGuide.ts`：页面内中英文速查规则及示例。

## 区块模式与 Markdown 的对应关系

| 区块字段 | Markdown 对应位置 |
| --- | --- |
| 姓名、职位、联系方式、头像 | 顶部 `name`、`title`、`contact`、`image` 字段 |
| 章节名称 | `##` 标题 |
| 章节介绍（可选） | `##` 后、第一条 `###` 之前的正文 |
| 职位 / 专业与学历 / 项目名称 | `###` 标题 |
| 时间 | `###` 后的 `| 时间` |
| 公司 / 学校 / 所属组织 | `###` 下一行的整行加粗文字 |
| 职责与成果 / 补充说明 / 项目成果 | 该条 `###` 下的正文或列表 |
| 技能清单、未分组的自定义章节 | `##` 下的正文，不会自动生成空的职位、公司和时间字段 |

“分点”按钮会把每个非空普通行转为列表项，保留已有列表标记；它只整理当前输入框，不会重写整份简历。章节上下箭头会同时调整预览与 Markdown 的顺序。删除操作可以用编辑区上方的“撤销”恢复。

经历的时间框旁可打开年月选择器：选择开始与结束月份，或勾选“至今”，然后点“应用日期”。关闭选择器不会修改原文。选择器使用 `YYYY.MM - YYYY.MM` / `YYYY.MM - 至今` 格式，并阻止结束月份早于开始月份；只有年份、预计毕业时间或其他说明仍可直接在时间框中手动填写。

这是一份当前项目的写法指南，不等同于完整的 Markdown 或 YAML 规范。基本信息区只支持 `name`、`title`、`contact`、`image` 四个单行字段，不支持任意嵌套 YAML 配置。
